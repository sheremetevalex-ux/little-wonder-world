# Little Wonder World

A wordless world of seventeen games for small children, most of them now in real 3D: soft vinyl-toy characters with glossy eyes, squash and stretch, soft shadows and studio lighting.

New: **Dumplings** (four treats that each open their own way, with 32 collectible toys and a shelf to keep them), **Magic Eggs** (warm an egg until it knocks back, crack it, raise the baby with magic berries until it transforms twice), **Squishy Studio** (soft-body toys you can dent, stretch until they sing, paint and decorate), **Hidden Treasures** (puppies hiding in six 3D places, three rounds each, freshly arranged every time, with a torch at night) and **Sky Jump** (a one-finger climbing platformer through six worlds with power-ups, bees, checkpoints and a rescue bubble).

Rebuilt in 3D: the hub, the splash, the pet house (bath, kitchen, bedroom), the bakery, the pop toy and the singing garden. Still in 2D: dress-up, salon, atelier, café, rubber faces, slime, painting and the journey.

**Play:** https://sheremetevalex-ux.github.io/little-wonder-world/

No ads, purchases, accounts or tracking. Everything stays on the device. Works offline after the first launch.

## Install

- **iPhone / iPad (Safari):** Share button → *Add to Home Screen*.
- **Android (Chrome):** menu ⋮ → *Install app* (or use the button on the first screen).

## How it's built

Plain ES modules with two layered canvases: three.js (bundled into `src/vendor/three.js`, no CDN) draws the 3D worlds, and a 2D canvas on top draws buttons, particles and hints. All art and all sound are generated by code, so there are no asset files to load, and it looks and sounds the same on every device.

| Path | Purpose |
| --- | --- |
| `src/core/` | engine (loop, touch, buttons, tweens), the 3D stage (`stage.js`: renderer, lights, toy materials, picking), audio synthesis with wordless character voices, generative music, particles, saves |
| `src/art/` | 3D creatures and accessories (`critter3d.js`), 3D world toys for the hub, the 2D friends, doll and wardrobe |
| `src/scenes/` | one file per activity, plus the hub, splash and album |
| `tools/build.mjs` | assembles `dist/`, stamps the offline cache version |
| `tools/vendor.mjs` | rebundles three.js into `src/vendor/three.js` (only needed after a three.js update) |
| `tools/make-icons.mjs` | re-renders icons and launch images from the game art |
| `tests/monkey.mjs` | random-finger test on iPhone, iPad and Android emulation, with the sound muted |

**Friends:** everyone found lives in the house in the album, and a heart on a window means that friend is out on the meadow (tap to swap). Once all 24 are found, eggs bring them back wearing a golden crown, a second collection of the same size.

**Add a game:** create a scene (`enter`, `update`, `draw`, `down`, `move`, `up`; give it a `stage = new Stage()` for 3D), register it in `src/main.js`, add it to `WORLDS` in `src/scenes/hub.js` and a toy for its bubble in `src/art/worldtoys.js`.

**Run locally:** `npm start`, then open http://localhost:5199. `PORT=5198 OUT=some/folder npm test` runs the random-finger test against another port and saves its screenshots elsewhere.

**Release:** push to `main`. GitHub Actions builds and deploys; installed apps pick up the new version on their next launch. Hosting on GitHub Pages is free.
